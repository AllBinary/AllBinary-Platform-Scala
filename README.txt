                             AllBinary Platform Scala

What is it?

This repository contains code generated by the AllBinary Platform for support in Scala.  
This repo is used to allow developers to skip the Scala code generation step.

What are some example games with this Scala code?

https://allbinary.itch.io (The downloads with "-scala" in the filename are Scala only builds. Currently that only includes nothing. Also the Scala builds are not available on Google Play or other stores.)
